# DockPhobia
## Description
* Ever wanted to use your taskbar? Well now you can't using the all new, marginally improved DockPhobia. With this, you will never be able to touch your taskbar, rendering it practically useless. After years of clicking torture, the taskbar has become so frightened of the mouse it refuses to even be near it.
* Coded in Python and using Apple Script after failed attempts in swift.
